Horse Data Repository

This project contains comprehensive JSON files with information about horses.

The following data files are available:

  • horse_breeds.json - Different horse breeds, their origins, and characteristics
  • horse_colors.json - Horse coat colors, patterns, and markings
  • horse_anatomy.json - Horse body structure, proportions, and measurements
  • horse_behavior.json - Horse movements, behaviors, and communication
  • horse_mythology.json - Mythical and fictional horses
  • horse_visualization.json - Information for visualizing horses in 2D and 3D

A UI for exploring this data will be developed in a future iteration.
